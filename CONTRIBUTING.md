# Contributing to MEDI-Diagnose

## How to contribute

1. Fork the repo
2. Create a branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Commit: `git commit -m "feat: your change"`
5. Push and open a Pull Request

## Good areas to contribute

- New diagnostic modules (new disease/organ)
- Model accuracy improvements
- Frontend UI improvements
- Additional test coverage

## Notes

- Do not include large model files in the repo — link them externally or use DVC
- Mental health and medical features should include appropriate disclaimers
